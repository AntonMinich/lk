# Кабинет партнёра fincode

Макет личного кабинета партнёра: вход, регистрация и список заявок.

## Как смотреть

`localhost:5173` открывается только на том компьютере, где запущена команда `npm run dev`. В Cursor Cloud это превью-ссылка агента, не ваш ноутбук.

- Вход: `/`
- Регистрация: `/register`
- **Список зарегистрированных партнёров: `/partners`**
- JSON с сервера: `/api/partners`
- Проверка API: `/api/health`

Если открыт GitHub Pages, сервера нет: заявки сохраняются в браузере, 404 у `/api/register` больше не ломает отправку.

## Запуск на своём компьютере

```bash
npm install
npm run dev
```

Затем http://localhost:5173
