# Кабинет партнёра fincode

Два кабинета в одном приложении:

- **Кабинет партнёра** — `/` вход, `/register` заявка, `/cabinet` после одобрения
- **Админка** — `/admin` вход сотрудников, `/admin/applications` заявки

## Как это устроено без Node.js

Пока сервер не установлен у вас на компьютере и GitHub Pages отдаёт только статику, заявки живут в **этом браузере** (`localStorage`). Схема такая:

1. Партнёр открывает `/register` и отправляет заявку.
2. В **том же браузере** сотрудник открывает `/admin`, входит как `admin` / `fincode`.
3. В списке заявок нажимает **Одобрить**.
4. Партнёр на `/` входит по телефону и паролю — кабинет открывается.

Другой браузер, другой компьютер или режим инкогнито заявку не увидят. Когда появится свой API, тот же статус `pending → approved` поедет на сервер.

## Страницы

- Вход партнёра: `/`
- Регистрация: `/register`
- Кабинет партнёра: `/cabinet`
- Вход в админку: `/admin`
- Заявки: `/admin/applications`
- Проверка API: `/api/health`

## Запуск на своём компьютере

```bash
npm install
npm run dev
```

Затем http://localhost:5173 — здесь уже работает сервер, и одобрение не зависит от одного браузера.
