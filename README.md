# Кабинет партнёра fincode

Два кабинета в одном приложении:

- **Кабинет партнёра** — `/` вход, `/register` отдельная страница заявки, `/cabinet` после одобрения
- **Админка** — `/admin` вход сотрудников

Экраны входа и админка оформлены как FINCODE OS: метка **FINCODE OS**, бейдж DEMO, KPI-карточки в списках заявок.

## Кабинет партнёра

`/register` — отдельная страница заявки на регистрацию партнёра, не карточка входа. Нужно скачать и подписать договор о сотрудничестве, указать наименование юрлица, УНП, ФИО контактного лица, телефон и email, затем загрузить сканы: подписанное соглашение, свидетельство о регистрации и устав. После одобрения вход: телефон и УНП как временный пароль.

Интерфейс кабинета и админки следует правилам **FINCODE OS** (`AntonMinich/dashboard`): Inter, бирюзовый бренд `#0f766e`, фон canvas `#f5f7f9`, белые карточки, компактные кнопки и таблицы со светлой шапкой.

- **Мои заявки** — таблица на всю ширину в стиле истории. Клик по строке открывает карточку заявки (данные, статус, менеджер).
- **Создать заявку** — форма: организация, контакт, телефон, предмет лизинга, сумма, срок. После отправки заявка со статусом «На рассмотрении» появляется в списке и в админке в разделе **Заявки на лизинг**.
- **Калькулятор** — предварительный расчёт платежа; оттуда можно перейти к оформлению заявки.
- **Уведомления** — колокольчик в шапке: смена статуса заявки и назначение менеджера.

## Админка

После входа (`admin` / `fincode` или `admin2` / `fincode2`) слева меню разделов, сверху справа — уведомления, имя сотрудника и иконка. По клику на иконку: **Мой профиль** и **Выйти**. Сессия сохраняется в браузере: обновление страницы не выкидывает из кабинета.

- Заявки на регистрацию партнера — `/admin/partners`
- Заявки на лизинг — `/admin/leasing`
- Профиль сотрудника — `/admin/profile`
- Уведомления — колокольчик в шапке и `/admin/notifications` (новые заявки на регистрацию и лизинг)

Клик по строке открывает карточку заявки. Справа — ответственный менеджер, кнопки **Принять**, **Одобрить**, **Отклонить**, **Сменить менеджера** и ссылка **История**. После принятия заявка «В работе», после одобрения — «Активен».

## Страницы

- Вход партнёра: `/`
- Регистрация: `/register`
- Кабинет партнёра: `/cabinet` → `/cabinet/applications`
- Мои заявки: `/cabinet/applications`
- Карточка заявки: `/cabinet/applications/:id`
- Новая заявка на лизинг: `/cabinet/applications/new`
- Калькулятор: `/cabinet/calculator`
- Уведомления партнёра: `/cabinet/notifications`
- Вход в админку: `/admin`

## Запуск на своём компьютере

```bash
npm install
npm run dev
```

Затем http://localhost:5173
